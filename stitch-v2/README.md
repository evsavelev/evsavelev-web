# Stitch v2 — автономная сравнительная версия

Публичный адрес: https://evsavelev.github.io/evsavelev-web/stitch-v2/

Визуальная система: пользовательский экспорт Stitch, Swiss Cyber Precision. Графит, один зелёный акцент, плотная сетка. Все изображения, шрифты и код локальны в этой папке. Нет runtime-зависимости от основного сайта, CDN, фреймворка или видео.

Сборка: `node stitch-v2/build.cjs` из корня репозитория после основной сборки. Скрипт копирует только production-файлы в `dist/stitch-v2/` и не меняет остальные файлы `dist`.

Локальная проверка: `node stitch-v2/qa.cjs` при сервере на http://127.0.0.1:4193/evsavelev-web/stitch-v2/. Другой адрес задаётся через `QA_URL`. Нужны npm devDependencies репозитория и Chrome.

Данные: реальные 10 проектов из data/projects.json актуального main306e203; проверенные контакты владельца из ТЗ; текущие стартовые цены 35/60/100/130/160 тысяч рублей. CMS/backend/CRM/SLA/сроки и коммерческие показатели не обещаются.

Форма: локальная подготовка сообщения, затем явный переход посетителя в WhatsApp, e-mail либо копирование для Telegram/MAX. Никаких запросов на отправку с сервера, сохранения данных или ложных сообщений об отправке.

Индексация отключена: noindex, nofollow; canonical на основную версию. Папка не добавляется в sitemap.

Основной сайт сохранён на main306e203. Предыдущий синий редизайн зафиксирован в checkpoint/premium-dark-redesign (db8c70f); не смешан с действующим публичным сайтом.

Изменение вне этой папки: одна добавочная команда в .github/workflows/pages.yml, запускающая автономную сборку после основной. В root-interface файлах изменений нет.
