## Локальная проверка

Ширины **360 / 390 / 430 / 768 / 1024 / 1440**, DPR 1, touch-эмуляция для телефонов. Исходный отчёт — `verification/local-qa.json`, скриншоты — локальная папка `qa/local/`.

- HTTP 200, восемь работ, все WebP загружены, alt и размеры присутствуют.
- Горизонтального overflow нет на всех шести ширинах. Видимые интерактивные элементы высотой не менее 44px.
- Меню, якоря, диалог контактов, touch, Tab-цикл, Escape, закрытие кнопкой, возврат фокуса.
- Нижняя панель скрывается при открытом диалоге; нижний запас footer и CSS safe-area предусмотрены. Проверено в эмуляции, физический iPhone/Android не использовался.
- MAX копирует `+79088990088`. При запрете Clipboard API честно показывает номер для ручного копирования.
- Без JS доступны навигация, весь контент и ссылка нижней панели на контакты. Reduced-motion выключает появление/трансформации; обычный motion открывает контент при прокрутке.
- Все восемь внешних сайтов HTTP 200. Проект открывается в новой вкладке; возвращение → контакты работает.
- Настоящий HTTP 404 с `noindex` и ссылкой на главную. Sitemap, robots, favicon и OG доступны.
- Ошибок console/page при основных сценариях нет. Ожидаемая ошибка загрузки проверяемого 404 не считается неожиданной ошибкой страницы.
- Формы и ложных сообщений об отправке нет. Все email-ссылки и Person используют подтверждённый адрес.

2. После touch-открытия диалога фокус не возвращался на скрывавшуюся нижнюю кнопку — сохраняется инициатор, панель раскрывается до возврата фокуса.

4. Для no-JS добавлена видимая мобильная навигация.
