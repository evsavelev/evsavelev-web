## Поведение и доступность

Обычная загрузка с JS: сетка скрыта CSS до инициализации, затем `hidden`. Ссылки внутри не попадают в Tab и изображения не запрашиваются. Hero использует нативный button с aria-controls/expanded и раскрывает все карточки за один клик. Заголовок получает программный фокус; прокрутка плавная, при reduced-motion мгновенная. Кнопка раздела меняется на «Скрыть работы», закрывает сетку из верхней точки без перемещения из конца длинной галереи. Оба aria-expanded синхронизированы.

Навигация и прямой #work раскрывают сетку. После мобильного меню фокус направлен на заголовок работ, а не на уже закрывшееся меню. Без JS обычная hero-ссылка и все карточки доступны; существующий контактный fallback сохранён. Исходный HTML содержит все десять работ, корректные ссылки/alt/lazy; title/canonical/Person/OG не менялись. Это одинаковое пользовательское поведение для браузеров, не специальное представление для поисковых роботов; индексация не заявляется как подтверждённая.
