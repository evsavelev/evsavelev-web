# Евгений Савельев — сайты для бизнеса

Актуальные мобильные контакты: постоянная нижняя fixed-панель удалена. Hero предлагает работы и бесплатное демо; прямые контакты доступны из меню, блока «Обо мне» и внизу страницы. MAX использует подтверждённую персональную ссылку, без копирования номера. Исторические QA-отчёты сохранены, регрессия запускается через `npm run qa`, новая форма — `node scripts/qa-commercial.cjs`.

Коммерческий сайт-портфолио независимого исполнителя. Десять работ, пять направлений услуг, процесс и прямые контакты. Без вымышленных отзывов, цен, опыта и результатов продаж. Сетка работ по умолчанию закрыта при JS, раскрывается hero-кнопкой и toggle в разделе; прямой #work открывает её, без JS все работы доступны сразу. Порядок и подтверждённые источники новых проектов — `PORTFOLIO-UPDATE.md`.

## Запуск

Node 22+, установленный Google Chrome для QA.

```sh
npm ci
npm run build
npm start
# http://127.0.0.1:4190/evsavelev-web/
npm run qa
node scripts/performance.cjs
```

В PowerShell с запретом `.ps1` используйте `npm.cmd`. Для публичного QA установите переменную `QA_URL=https://evsavelev.github.io/evsavelev-web/`. Отчёты и скриншоты сохраняются в `qa/local` или `qa/public`; компактные подтверждения выпуска — в `verification/`.

## Содержание и материалы

- `index.html` — семантическая страница-шаблон с контактами и метаданными.
- `data/projects.json` — выбранные работы и фактические выполненные элементы.
- `scripts/build.cjs` — вставляет портфолио в HTML, копирует ресурсы, создаёт sitemap и robots. Результат в `dist/`.
- `assets/portfolio` — настоящие снимки опубликованных сайтов, WebP 720/1440. Происхождение — `data/media.json`.
- `scripts/capture-portfolio.cjs` — повторное снятие desktop-превью. `scripts/prepare-assets.py` — Pillow/requests, WebP и локальный Inter с OFL.
- `assets/og.jpg` — типографическое изображение 1200×630; `scripts/make-og.cjs` пересоздаёт его при запущенном локальном сервере.
- `DESIGN.md`, `RESEARCH.md`, `QA.md`, `SEO-AUDIT.md` — направление, отбор и проверки.

Статическая форма в `request.js` подготавливает сообщение; собственного endpoint и хранения данных нет. WhatsApp получает полный текст в URL, Telegram/MAX — копирование текста и переход на подтверждённый профиль, email — mailto с темой и телом. Пользователь отправляет обращение самостоятельно. Отказ clipboard или блокировка окна оставляют текст и прямую ссылку для ручного продолжения. При закрытии формы поля очищаются. Адрес email, ссылка MAX и портрет предоставлены владельцем.

`data/services.json` содержит шесть согласованных предложений: бесплатное демо и пять платных форматов от 35 / 60 / 100 / 130 / 160 тыс. ₽. Демо — концепция, без договора, предоплаты и обязательств продолжать. Для платных проектов заявлены запуск под ключ и 12 месяцев коммерческого хостинга; последующее размещение и регистрация домена оплачиваются отдельно. Домен оформляется на клиента.

Checkpoint перед коммерческими блоками: `before-pricing-demo-form` (`a26b7a6a6d6a4d17d5622761b7f640f7ab9550b7`). Реализация подготовлена в `feature/pricing-demo-form`.

## Выпуск и восстановление

GitHub Actions собирает `dist` и публикует Pages при push в `main`. История сохранена; checkpoint до реализации — tag `pre-implementation`, готовая локальная версия — `v1-local-qa-checkpoint`. Для исправления опубликованного изменения используйте `git revert <commit>` и обычный push в main; Actions опубликует восстановленную версию. Не делайте force-push и не меняйте клиентские репозитории.

`robots.txt` лежит в каталоге проекта. Для управления обходом домена файл нужен в корне `evsavelev.github.io`; этот отдельный проект его не меняет. Sitemap можно указать в Search Console после подтверждения владения. Индексация и поисковые результаты не заявляются как уже полученные.
